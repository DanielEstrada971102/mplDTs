DTRelatedPatch

The DTRelatedPatch class serves as the foundational base for all DT-related patches. It provides a unified interface for applying Affine2D transformations to matplotlib patches that represent various DT objects. These transformations are based on the geometry of the DT Station where the object resides.

This class was designed to ensure that all DT-related objects drawn as matplotlib patches share consistent Affine2D transformations, aligning them with the DT Station’s geometry.
